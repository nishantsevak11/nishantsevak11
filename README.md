<h2 align="center">🚀 Deep Dive: Featured Projects</h2>

<details open>
<summary><b>🏭 Opexee Mimic Designer (Industrial HMI)</b></summary>
<br>
<div style="background-color: #0d1117; padding: 15px; border-radius: 10px; border: 1px solid #30363d;">
<b>Problem:</b> Industrial clients needed a web-based, CAD-like tool to design SCADA interfaces without installing heavy desktop software.
<br><br>
<b>Solution:</b> Built a high-performance React application that acts as a visual editor for industrial systems.
<ul>
<li><b>Dynamic Rendering Engine:</b> Created a system where every component (pump, tank, sensor) is defined by a JSON schema. The engine parses this schema to render interactive SVGs that animate based on live MQTT data.</li>
<li><b>Smart Connection Logic:</b> Used standard vector math to implement "smart pipes" that automatically route around obstacles and snap to valid connection points on machinery.</li>
<li><b>Performance:</b> Optimized the rendering loop to handle 1000+ nodes on a single canvas without dropping below 60fps using React.memo and virtualization.</li>
</ul>
</div>
</details>

<br>

<details>
<summary><b>⏳ LegacyNote (Digital Legacy Platform)</b></summary>
<br>
<div style="background-color: #0d1117; padding: 15px; border-radius: 10px; border: 1px solid #30363d;">
<b>Problem:</b> Ensuring a message is delivered exactly 20 years from now, even if servers crash or databases change, is a difficult distributed systems problem.
<br><br>
<b>Solution:</b> A Serverless "Dead Man's Switch" architecture.
<ul>
<li><b>Scheduling:</b> Instead of simple cron jobs, I utilized <b>QStash</b> to push webhooks to <b>Azure Serverless Functions</b>. This separates the scheduling logic from the application logic, ensuring zero downtime affects delivery.</li>
<li><b>Video Generation:</b> Users can write a text letter, which my backend converts into a video with scrolling text and background music using a custom <b>Puppeteer + FFmpeg</b> microservice running in a Docker container.</li>
</ul>
</div>
</details>
